## 📌 Project Overview

Hotel Njenka is a fictional premium hotel website designed to provide:
- Room booking functionality
- Hotel information and services
- Photo gallery
- Contact details
- Smooth user experience with modern UI design

The goal of this project is to demonstrate **real-world front-end development skills**.

---

## ✨ Features

### 🧭 Navigation
- Sticky navigation bar
- Mobile-friendly hamburger menu
- Smooth scrolling between sections

### 🏨 Hotel Sections
- Hero landing page with call-to-action
- About section with hotel description
- Rooms with pricing and amenities
- Services offered by the hotel
- Image gallery section
- Contact information section

### 📝 Booking System
- Interactive booking form
- Date validation (check-in/check-out)
- Price calculation based on room type
- Booking confirmation popup

### 📱 Responsive Design
- Fully responsive on mobile, tablet, and desktop
- Clean layout using CSS Grid and Flexbox

---

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and responsive design
- JavaScript (ES6) – Interactivity and form handling
- Google Fonts – Typography
